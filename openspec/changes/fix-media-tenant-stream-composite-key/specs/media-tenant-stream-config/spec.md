## ADDED Requirements

### Requirement: 租户流配置使用租户和节点作为唯一键

`media`插件 SHALL 将租户流配置的业务唯一键定义为租户 ID 和节点编号的组合。同一租户可以在不同媒体节点上拥有独立流配置，同一租户在同一节点上只能存在一条有效配置。

#### Scenario: 同一租户配置多个节点

- **WHEN** 管理员为同一租户 ID 分别创建两个不同节点编号的租户流配置
- **THEN** 系统应保存两条独立记录
- **AND** 列表查询应返回这两条记录

#### Scenario: 同一租户同一节点重复配置

- **WHEN** 管理员为已存在的租户 ID 和节点编号再次创建租户流配置
- **THEN** 系统应拒绝创建重复配置
- **AND** 不得影响该租户在其他节点上的配置

### Requirement: 租户流配置删改按复合键定位

`media`插件 SHALL 在租户流配置详情、更新和删除操作中同时使用租户 ID 和节点编号定位目标记录。

#### Scenario: 更新指定节点配置

- **GIVEN** 同一租户在节点 A 和节点 B 分别存在租户流配置
- **WHEN** 管理员更新该租户在节点 A 的配置
- **THEN** 系统应只修改节点 A 的配置
- **AND** 节点 B 的配置保持不变

#### Scenario: 删除指定节点配置

- **GIVEN** 同一租户在节点 A 和节点 B 分别存在租户流配置
- **WHEN** 管理员删除该租户在节点 A 的配置
- **THEN** 系统应只删除节点 A 的配置
- **AND** 节点 B 的配置保持可查询
