# 修正媒体租户流配置复合唯一键

## 背景

`media`插件的租户流配置用于维护租户在不同媒体节点上的流并发和启用状态。现有实现把租户 ID 作为单一资源标识，导致同一租户无法为多个节点保存独立配置，更新和删除也会按租户误定位记录。

## 范围

本变更将租户流配置的唯一语义修正为`tenantId + nodeNum`。后端表约束、服务查询、详情、更新、删除和前端 API 调用都必须使用复合键定位目标记录，并补充能够复现同一租户多节点配置的自动化验证。

## 非目标

- 不改变媒体节点、设备节点、策略绑定或租户白名单的业务语义。
- 不引入新的租户来源、租户展示名称解析或跨插件租户管理能力。
- 不修改管理端整体页面布局。
