## 背景

媒体插件独立接口文档页的管理端接口全部声明为同一个`媒体管理`分组，Stoplight Elements 只能按 OpenAPI `tags` 做一级归类，导致左侧导航在单个分组下堆叠过多接口，浏览和定位成本较高。

## 变更

- 将媒体插件管理端接口按资源职责拆分为多个 OpenAPI 一级分组。
- 保持现有 HTTP 路由、请求响应 DTO、权限标签、插件运行边界和宿主核心契约不变。
- 增加后端验证，确保插件自有 OpenAPI 文档持续输出清晰的管理端分组。

## 影响

- 修改范围限定在`apps/lina-plugins/media/`源码插件和本次`OpenSpec`记录，不修改`apps/lina-core`宿主核心能力。
- `i18n`影响：`media`插件未启用`i18n`，本次仅调整单语言插件的 API 文档源 tag，不要求维护插件`manifest/i18n`资源。
- 数据权限影响：不新增或修改业务数据读取、写入、导出、聚合或可见性边界。
- 缓存一致性影响：不新增或修改缓存、快照、失效或集群一致性逻辑。
- 开发工具跨平台影响：不修改`Makefile`、脚本、`CI`、代码生成或`linactl`入口。
