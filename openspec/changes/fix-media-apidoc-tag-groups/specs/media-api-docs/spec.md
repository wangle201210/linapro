## ADDED Requirements

### Requirement: 媒体插件管理端接口文档必须按资源分组
媒体插件 SHALL 在自有 OpenAPI 文档中按管理端资源职责输出接口`tags`，避免所有管理端接口聚合到单个粗粒度分组中。

#### Scenario: 浏览媒体插件独立接口文档
- **当** 用户打开媒体插件独立接口文档页
- **则** 管理端接口按媒体策略、节点管理、设备节点、流别名、策略绑定、租户流配置和租户白名单等资源职责展示为多个一级分组
- **且** mediaopen 的 token 策略查询和租户白名单 IP 查询展示在`内部接口`分组下
- **且** 现有 HTTP 路由、权限标签和请求响应字段保持不变
