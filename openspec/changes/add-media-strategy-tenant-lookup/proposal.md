# 新增媒体策略绑定反查接口

## 背景

`media`插件已经提供租户和设备策略绑定列表接口，但当前只能按租户 ID 或设备 ID 模糊查询。调用方需要在已知媒体策略 ID 时快速查询绑定到该策略的租户列表和设备列表，并且租户查询只关注租户策略表`media_strategy_tenant`，设备查询只关注设备策略表`media_strategy_device`，不包含租户设备策略表`media_strategy_device_tenant`的数据。

## 范围

本变更新增只读 HTTP API，用于按策略 ID 分页查询租户策略绑定和设备策略绑定。接口应保持分页边界，复用现有策略绑定权限标签，并在数据库侧使用对应绑定表的`strategy_id`等值过滤。同时，媒体管理端列表接口的单页上限统一调整为`10000`，由 DTO 校验和服务层分页收敛共同约束。

## 非目标

- 按策略反查租户或设备时，不查询租户设备策略绑定表。
- 不修改策略绑定写入语义。
- 不修改前端页面工作流。
