## 背景

甲方补充的`功能模块参数.md`要求中，已实现的`寻牛活动`插件还存在三个实现缺口：激活海报和电子证书只输出基础占位`PNG`，基础互动规则和排行榜规则停留在启动配置，运营管理端缺少独立排行榜数据查看入口。

## 变更

- 将激活海报和电子证书渲染器升级为携带活动信息、玩家信息和奖项信息的最终可展示`PNG`。
- 新增插件自有运行规则配置能力，让运营端可以查看和维护签到、偷草、送草、铁牛加成、排行榜、风控阈值、海报标识和小程序回跳地址等参数。
- 让关键互动服务在请求路径读取共享运行规则，使运营侧更新的规则实时参与玩家端业务校验和排行榜/风控统计。
- 在运营结算页新增排行榜数据查看区，覆盖喂草榜、院系榜和好友榜投影。
- 补齐小程序真实模式依赖的运行时公开配置、牛只安全地图与详情、标准化照片上传、稳定幂等写入、好友动态和组队云搬牛接口，并允许后到玩家继续激活已首发牛只获得自己的卡片。
- 接通`cow-mini`生产适配器，移除配置、上传、动态和组队贡献占位实现，同步发布 OpenAPI 与自动化契约测试。
- 新增小程序配置维护、牛只批量导入、照片审计和错误激活撤销接口，形成上线前数据准备与运营审计闭环。

## 影响

- 修改范围限定在`apps/lina-plugins/sicau-niu/`源码插件、`cow-mini`小程序及本次`OpenSpec`记录，不修改`apps/lina-core`宿主核心契约。
- 数据权限影响：新增运营读写接口受宿主`Auth+Tenancy+Permission`链和插件权限码保护；玩家端仍通过玩家 token 自隔离。
- 缓存一致性影响：规则配置以插件自有数据库表为权威数据源，不新增进程内缓存或分布式缓存，更新后下一次请求读取最新值。
- `i18n`影响：该插件未启用`i18n`，新增管理端文案和插件菜单权限仍按单语言插件处理。
- 开发工具跨平台影响：不修改`Makefile`、脚本、`CI`或`linactl`入口；仅使用既有`make dao`生成插件`DAO/DO/Entity`。
- 小程序接口影响：新增接口继续位于`sicau-niu`插件路由下；公开配置不返回密钥，照片、动态和协作状态均由玩家 token 隔离。未激活牛只只返回固定模糊区域，激活后才返回精确坐标。
- 数据库影响：新增插件自有照片、云搬牛团、唯一有效成员绑定、上报事实记录、个人上报基准点和小程序运行配置表，并为关键写接口补充幂等键；每次首次成功受理的位置上报，包括首次基准点和零距离上报，都保存可供统计与审计的权威事实记录。照片、无效团、历史成员与上报记录作为业务审计数据保留，不提供用户侧删除接口。有效团固定不超过`120`个且团名唯一，连续`72`小时没有成员成功加入或贡献上报的团自动失效、关闭成员绑定并释放名额与团名；位置上报按用户和北京时间自然日原子限制为最多`12`次，换团不重置。成员和上报明细分页，统计在数据库侧按索引聚合，不产生按返回行数增长的`N+1`查询或无约束全表扫描。
